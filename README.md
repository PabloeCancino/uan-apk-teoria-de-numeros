Aplicación interactiva para la enseñanza, modelado y simulación computacional de la **Teoría de Números** (`CBIMAT-256`), desarrollada bajo la norma **NTE-UAN-APK-001 v1.3** de la **Universidad Autónoma de Nayarit**.

---

## 🌟 Características Principales

1. **Temario Completo Oficial (5 Unidades)**:

   - **Unidad I: El anillo de los enteros \(\mathbb{Z}\)** (Peano, Buen Orden, Inducción, Algoritmo de la División, Algoritmo de Euclides, Identidad de Bézout, Ecuaciones Diofánticas y Ternas Pitagóricas).
   - **Unidad II: Primalidad y Factorización** (Primos, Coprimalidad, Criba de Eratóstenes, Teorema Fundamental de la Aritmética, Criptografía RSA y Métodos de Factorización de Fermat).
   - **Unidad III: Elementos de Combinatoria y Teoremas Clásicos** (Conteo, Triángulo de Pascal, Coeficientes Binomiales, Teorema de Wilson y Pequeño Teorema de Fermat).
   - **Unidad IV: Funciones Aritméticas** (Número de divisores \(d(n)\), Suma de divisores \(\sigma(n)\), Números Perfectos, Primos de Mersenne, Función \(\phi(n)\) de Euler e Inversión de Möbius \(\mu(n)\)).
   - **Unidad V: Anillo de Residuos Módulo \(n\)** (Congruencias, Sistemas de Residuos, Grupo de Unidades \(\mathbb{Z}_n^\times\), Teorema de Euler, Congruencias Lineales y Teorema Chino del Residuo CRT).
2. **Simuladores e Interactivos Especializados**:

   - **Algoritmo de Euclides & Identidad de Bézout**: Cálculo paso a paso de divisiones sucesivas y coeficientes enteros \(ax + by = \operatorname{mcd}(a,b)\).
   - **Criba de Eratóstenes Interactiva**: Animación de filtrado por números primos y conteo \(\pi(N)\).
   - **Resolutor de Ecuaciones Diofánticas**: Verificación de solubilidad y familia general de soluciones enteras.
   - **Calculadora de Funciones Aritméticas**: Descomposición canónica, \(d(n), \sigma(n), \phi(n), \mu(n)\) y clasificación de números perfectos.
   - **Reloj y Aritmética Modular**: Rueda interactiva de residuos, cálculo de inversos modulares y unidades coprimas.
   - **Teorema Chino del Residuo (CRT)**: Solución analítica paso a paso para sistemas de congruencias lineales.
3. **Simulador de Demostraciones Matemáticas**:

   - Visualización secuencial y justificada de demostraciones formales clásicas (Infinitud de primos de Euclides, Teorema Fundamental de la Aritmética, Teorema de Bézout, Teorema de Wilson, Pequeño Teorema de Fermat, Euclides-Euler).
4. **Centro de Evaluaciones Formativas**:

   - Banco de reactivos institucionales por cada unidad temática y Examen Global Integrador con explicaciones matemáticas KaTeX.
5. **Accesibilidad y Personalización**:

   - Soporte de 8 niveles de tamaño de fuente (\(0.85\times\) a \(2.00\times\)).
   - Modo Oscuro y Modo Claro de alto contraste.

## 🚀 Instalación y Ejecución

```bash
# Clonar el repositorio
git clone https://github.com/PabloeCancino/uan-apk-teoria-de-numeros.git
cd uan-apk-teoria-de-numeros

# Instalar dependencias
npm install

# Iniciar servidor de desarrollo local
npm run dev

# Compilar para producción
npm run build
```
